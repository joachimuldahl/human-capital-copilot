# Human Capital Copilot

Sizes your investment risk to your whole life, not just today's portfolio. Your future savings ("human capital") are usually your biggest asset: if your income is safe and bond-like you can carry more market risk; if it already moves with markets, less.

CBS team assignment (Jens, Damien, Joachim). Educational demo. Not investment advice. Data is illustrative.

**Live demo:** https://building-your-wealth.vercel.app/

## Run locally

```
npm install
npm run dev      # http://localhost:5173
npm test
npm run lint
npm run build
```

Stack: Vite + React + TypeScript, Tailwind CSS, React Router (HashRouter), Recharts, Zustand, Vitest. Full spec: [BUILD_SPEC.md](BUILD_SPEC.md).
