# Human Capital Copilot

**Live demo:** https://building-your-wealth.vercel.app/

Your biggest asset is usually your future salary. Human Capital Copilot sizes your investment risk to your whole life, not just today's portfolio. If your income is safe and bond-like, your portfolio can carry more stock-market risk. If your income already moves with the markets (finance, founders), it should carry less. Sixteen questions become one number, **Risk Capacity**: risk as a multiple of the global stock market (for example 1.50×). The app explains that number, compares it with your actual portfolio and shows a plan with a crash test.

> Educational demo. Not investment advice. Data is illustrative unless a factsheet source is shown.

## Features

- **Onboarding:** a currency choice (DKK, EUR, USD, GBP, SEK, NOK, CHF; the result is the same in every currency), then 16 questions in 4 steps, one per screen. Money questions take a typed amount plus a logarithmic slider. Each has a "Why we ask" panel with the research behind it and a live line showing how a different answer would change the result. A gauge updates on every answer and stays "Preliminary" until all questions are answered. Includes a knowledge check before borrowing can be switched on.
- **Results:** Risk Capacity with the limit that applies, four drivers (risk attitude, human capital, income type, limits), lifetime balance sheet, glide path to retirement and what-if sliders.
- **Portfolio:** demo portfolio or quick entry; risk fit (actual vs target), 2008-style crash test against your own loss limit, and ETF look-through by asset class, region, sector, single-company concentration and ETF overlap.
- **Plan:** safety gates (emergency buffer, expensive debt), gold and crypto satellites, target vs current allocation, example products ("Example, not advice"), crash test now vs target, borrowing panel with margin buffer and leveraged-ETF warning, and the steps to get there.
- **Method page:** the formulas with a worked example, every assumption with its justification, the fixed exchange rates, the sources of the verified product data, the limits, limitations and references.
- **Verified product data:** five example ETFs (VWCE, SPY5, EQQQ, AGGH, PHAU) use fees, top holdings and country and sector weights from the issuers' October 2026 factsheets, collected by Damien and audited in `docs/audit-damien.md`. All other product data is illustrative and marked as such.
- **Four demo people** (Sofie, Mads, Lea, Jonas) to explore without typing anything.
- Every number comes from a deterministic, unit-tested engine (`src/engine`). No AI-generated numbers; explanations are templates filled with engine results.

## Run locally

Requires Node 20.9 or newer.

```
npm install
npm run dev        # http://localhost:5173
npm test           # unit and page tests
npm run coverage   # engine coverage
npm run lint
npm run build
npm run data:etf   # regenerate the verified ETF data from Damien's CSVs
npm run zip        # submission ZIP of the last commit (no node_modules, dist or .git)
```

Stack: Vite + React + TypeScript (strict), Tailwind CSS, React Router (HashRouter), Recharts, Zustand (state saved in the browser), Vitest. No backend, no login.

## Project layout

- `src/engine/`: pure financial functions, all assumptions (`assumptions.ts`) and explanation templates
- `src/data/`: demo data: personas, products, ETF look-through, demo portfolios, FX rates. Five products use verified factsheet data (`verifiedEtfs.ts`, generated by `scripts/import-etf-data.mjs`); the rest is illustrative
- `src/store/`: persisted Zustand stores
- `src/pages/`, `src/components/`: the UI
- `BUILD_SPEC.md`: the full specification (source of truth)
- `docs/Application-Description.md`: the description document
- `prompts/`: the prompts used to build the app: `design-phase-log.md` (design phase with Claude), `PROMPT_LOG_AUTO.md` (build phase, verbatim), `PROMPT_LOG.md` (what the AI did per task) and `team/damien.md` (Damien's original prompts, mostly in French, with an English summary)
- `team/damien/`: Damien's delivery (demo data CSVs, notes, description draft); the issuer factsheet PDFs are kept out of the repo
- `docs/audit-damien.md`: the audit of that delivery

## Disclaimer

Educational demo, not investment advice. Five example products use verified issuer-factsheet data (as of 30–31 Oct 2026); all other product data, the demo people and their portfolios are illustrative. Exchange rates are fixed (ECB reference rates, 17 Nov 2026). The app never places orders.
